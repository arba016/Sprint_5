# Финальное задание 5-го спринта

Проект содержит автотесты Selenium для сервиса `qa-desk.education-services.ru`.

## Что проверяется

- Регистрация нового пользователя.
- Регистрация пользователя с email не по маске.
- Регистрация уже существующего пользователя.
- Login пользователя.
- Logout пользователя.
- Создание объявления неавторизованным пользователем.
- Создание объявления авторизованным пользователем.

## Запуск тестов

pytest

Для запуска используется Google Chrome. Драйвер создаётся и закрывается в фикстуре `driver`.
